# Metody zbierania informacji

### Środowisko pracy

Przykłądy przygotowane na zajęcia będą przygotowane w języku Python. Zalecana technologia pracy jest Python ale w ramach samo rozwoju można zastosować dowolną techologię.

### Plan kursu &#x20;

* Odczyt i weryfikacja danych
* Parsowanie i Walidacja danych
* Dane z REST API
* Web Scraping statyczny
* Web Scraping dynamiczny
* tworzenie i przetwarzanie danych z formularzy

### Opis kursu

Kurs „Metody Zbierania Informacji” ma na celu przekazanie kompleksowej wiedzy oraz praktycznych umiejętności z zakresu pozyskiwania danych ze źródeł internetowych. Uczestnicy zdobędą kompetencje niezbędne do bezpiecznego odczytu, parsowania i walidacji informacji. Program obejmuje zarówno integrację z interfejsami programistycznymi (REST API), jak i zaawansowane techniki pozyskiwania danych ze stron internetowych (web scraping statyczny i dynamiczny), a także automatyzację procesów związanych z obsługą formularzy sieciowych.
